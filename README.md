# Ollama-Bot
# 🤖 Bot de Telegram con IA local — Python + Ollama

Bot de Telegram desarrollado en **Python** que conecta la plataforma de mensajería con un modelo de inteligencia artificial ejecutado mediante **Ollama**, permitiendo interactuar con la IA a través de mensajes de texto de forma sencilla y directa.

## 🚀 Características

- 💬 **Conversación por texto:** interacción con el modelo de IA directamente desde Telegram.
- 🧠 **Inteligencia artificial local:** integración con Ollama para ejecutar el modelo de lenguaje.
- ⚙️ **Desarrollado en Python:** código orientado a una integración sencilla y flexible.
- 📱 **Integración con Telegram:** acceso al bot desde la aplicación de mensajería.
- 🔌 **Comunicación con Ollama:** envío de mensajes al modelo y recepción de respuestas generadas por la IA.

## 🛠️ Tecnologías utilizadas

- **Python** — lógica y funcionamiento del bot.
- **Telegram Bot API** — comunicación con los usuarios.
- **Ollama** — ejecución y gestión del modelo de lenguaje.
- **Qwen3.8:latest** — modelo de IA configurado para generar respuestas.

## 🎯 Objetivo del proyecto

Crear un asistente conversacional accesible desde Telegram, integrando Python con un modelo de inteligencia artificial gestionado mediante Ollama y explorando las posibilidades de ejecutar modelos de lenguaje en un entorno local.

## 📌 Próximas mejoras

- Gestión del contexto de las conversaciones.
- Manejo de errores y control de solicitudes.
- Configuración personalizada del modelo.
- Mejoras en la experiencia de usuario y en las respuestas del bot.
